# Running the next bring-your-own-bottle evening

The evening page is built once and reused: everything about an evening lives in the
database, so a new one needs no code. The first run was The Tally Get-Together
(12 October 2026), saved as the git tag `byob-v1`.

1. **Copy.** Host page, pick the last evening, *Copy to a new evening*. It arrives as a
   hidden draft with the same format, price range, description, seats and deadlines.
2. **Edit.** Change the title, page address, date, venue and bottle deadline. Set a new
   4-digit seat code. Save, then set the status to *Open*.
3. **Invite.** The *Invite on WhatsApp* box at the top of the evening: type a name, open
   WhatsApp, pick the chat. The message carries the link and the code.
4. **Bottles.** Guests photograph the label, check the details and set their price; the
   background and tasting note are written when they add it. *Write the missing notes*
   on the Bottles tab fills any gaps.
5. **After the night.** Tick the guests off on the Tally tab as they settle, set the
   evening to *Closed*, and add a short summary to Past dinners.

The home page shows the next open evening on its own; nothing to edit there.
